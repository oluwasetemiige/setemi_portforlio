# SETEMI Portfolio
Files: index.html, css/style.css, js/script.js

## Edit
- Email, phone, LinkedIn, Instagram: `CFG` at the top of js/script.js
- "What I do" details and the GitHub link for each project: the `D` array in js/script.js (add a repo URL as the 4th item of a project and a GitHub button appears)
- Skills: `SK`, featured projects: `PJ`

## Deploy to Vercel
`npx vercel` in this folder, then `npx vercel --prod`. Or push to GitHub, import at vercel.com/new, Framework Preset "Other", no build command.
